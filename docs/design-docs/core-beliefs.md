# 核心理念

1. **开发者信心优先于黑盒式可用性。** 每次重启都必须说明发生了什么，以及如何恢复。
2. **本机优先、隐私优先。** 除未来明确声明的集成外，工作区路径、源码和日志内容都只留在本机。
3. **唯一进程所有者。** 只有守护进程可以管理子进程生命周期；所有客户端只负责观察和请求操作。
4. **流数据存文件，事实存 SQLite。** 日志是仅追加的本机文件；SQLite 保存持久元数据、配置和聚合结果。
5. **渐进式披露。** 默认页面回答“什么需要关注”；原始事件和策略只需一次交互即可深入查看。
6. **为 Agent 可读性而设计。** 稳定 JSON 输出、类型化契约、确定性路径和已文档化的不变量都是产品能力。
7. **单机、无账户体验。** Dockyard 没有登录、个人资料、账户或 RBAC 界面，由当前操作系统用户在自己的机器上使用。
