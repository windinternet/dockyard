# 仓库初始化与 MVP 实施计划

## 结果

MVP 的本机控制平面已完成。实现保持了守护进程的唯一进程所有权，所有源码、日志与 SQLite 元数据均留在本机。

## 已交付

1. 已建立 pnpm 工作区、文档地图、CI 检查和单进程 Web 托管。
2. 已实现安全项目扫描、静态 PM2 转换预览、SQLite 迁移和幂等导入。
3. 已实现显式参数数组的子进程启动、停止、重启、带预算的指数退避与生命周期事件。
4. 已实现 stdout/stderr 本机文件写入和 SSE tail；日志正文未进入 SQLite。
5. 已实现真实数据的 Semi Web 面板，以及带稳定 JSON/JSONL、仅回环守护连接的 CLI。
6. 已实现运行时指标汇总、诊断导出和 UI/诊断展示脱敏。

## 关键决定

- 使用 Node 22 的 `node:sqlite`，由 `packages/db` 封装，避免 SQLite 或运行时状态泄漏到其他包。
- PM2 配置仅接受 JSON 或保守的静态字面量子集；绝不执行生态配置文件。
- 项目导入验证候选 cwd 位于项目根目录中；守护进程使用 `shell: false` 启动应用。

## 验证

- `pnpm check`
- `pnpm test`
- `pnpm build`
- 在隔离状态目录进行 API/CLI 端到端验证：扫描、重复导入、启动、SSE、事件、指标、诊断和停止。
